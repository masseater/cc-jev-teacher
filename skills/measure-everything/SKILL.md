# 全てを計測せよ


## エラーを握りつぶさない

- エラーは、呼び出し元に返すか、ログを出してから投げ直すか、ログを出して `"unavailable"` のような状態を返して画面に出す。
- ログを出さずに、`.catch(() => 既定値)` や `?? 既定値`、`Effect.orElseSucceed` などでエラーを消さない。

## 計測できているか確かめる


## 数字を出すとき

- 数える前に、その操作がログに残ることをdevで確かめる。0件のときも、記録されていないだけではないかを確かめる。
- 頻度は期間・全体の件数・失敗の件数を、レイテンシはp50 / p90 / p99 / 最大と件数を出す。

## 取れなかったことを隠さない

- 取れなかったものは、「取れなかった」と理由を添えて書く。見たことと推測は分けて書く。
- 「直った」は、直す前の状態をdevで再現し、直した後に結果が変わったのを見てから言う。
