# 全てを計測せよ

## 考え方

- エラーは握りつぶさない。呼び出し元に返すか、ログを出してから扱う。
- 数字や原因は、実際に記録されたものから言う。取れなかったことは取れなかったと書き、見たことと推測を分けて書く。

## エラー処理を書くとき

1. エラーは、呼び出し元に返すか、ログを出してから投げ直すか、ログを出して「取れなかった」ことを画面に出す。
2. ログを出さずに既定値で置き換えない。
3. devでエラーと成功を1回ずつ起こし、ログが見つかって原因が分かることを確かめる。確かめるまで完了にしない。

## 数字を出すとき

1. その操作がログに残ることを、devで確かめる。
2. 全件が残るログから数える。検索の上限に達したら、全部取り切る。
3. 頻度は期間・全体の件数・失敗の件数を、レイテンシはp50 / p90 / p99 / 最大と件数を出す。0件のときは、記録されていないだけではないかを確かめる。

## 「直った」と言うとき

直す前の状態をdevで再現し、直した後に結果が変わったのを見てから言う。
