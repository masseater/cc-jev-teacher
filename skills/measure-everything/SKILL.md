# 全てを計測せよ

## エラー処理を書くとき

1. エラーは、呼び出し元に返すか、ログを出してから投げ直すか、ログを出して「取れなかった」ことを画面に出す。ログを出さずに既定値で置き換えない。
2. devでエラーと成功を1回ずつ起こし、ログから原因が分かることを確かめてから完了にする。

## 数字や原因を報告するとき

1. その操作がログに残ることを、devで確かめる。
2. 全件が残るログから数える。検索の上限に達したら、全部取り切る。
3. 頻度は期間・全体の件数・失敗の件数を、レイテンシはp50 / p90 / p99 / 最大と件数を出す。0件のときは、記録されていないだけではないかを確かめる。
4. 見たことと推測を分けて書く。取れなかったものは、取れなかったと書く。

## 「直った」と言うとき

直す前の状態をdevで再現し、直した後に結果が変わったのを見てから言う。
