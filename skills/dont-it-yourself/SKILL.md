# 自前で作らない

既存のものがあればそれを使う。既存の関数を包むだけのラッパーも作らない。

1. [references/libraries.md](references/libraries.md) にその場面で使うものが載っていれば、それを使う。
2. 載っていなければ、Effectのモジュール、リポジトリにすでに入っている依存、npmの順に探す。RFC・W3C・ECMA・ISOなどの規格や広く使われている形式を扱う処理は、ライブラリがある前提で、規格の名前と番号、形式の名前、扱うデータの名前でnpmを検索する。
3. 候補が複数あれば、今もメンテナンスされていて、型定義があり、依存が少ないものを選ぶ。
4. 既存のもので足りない部分だけを書く。拡張用のAPIやオプションがあれば、それで足す。
