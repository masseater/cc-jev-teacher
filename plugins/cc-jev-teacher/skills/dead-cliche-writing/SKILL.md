# クリシェを消して平易に書く

クリシェは言い換えずに、欠けている情報（誰が、何を基準に、何をするか）を書いて置き換える。

## 手順

1. 対象は引数のファイル、なければ直前に書いた文章にする。ファイルがなければstdinに流す。
2. 文書に合うプリセット（既定は `paper`）で機械チェックを回し、出た違反は再判定せずにすべて直す。
   `bun "${CLAUDE_PLUGIN_ROOT}/node_modules/.bin/dead-cliche" check <対象ファイル> --preset <paper|business|chat>`
3. 機械で検出できないルールを出し、自分で確かめる。
   `bun "${CLAUDE_PLUGIN_ROOT}/node_modules/.bin/dead-cliche" list --manual`
4. 各違反は、`explain <rule-id>` で引いたルールのask（何を書くべきかの問い）に答える形で書き直す。
5. 0件になるまで、書き直しと再チェックを繰り返す。

## 書き直しの規律

- 固有名詞・数値・否定は、書き直しの前後で一致させる。
- 比喩は、指していた事実を特定してから消す。特定できなければ文ごと削る。
- 誇張は、数値か根拠を足して弱める。材料がなければ形容だけを外す。
- 語尾は敬体にする。原文全体が常体なら常体のまま。

## 出力

- 修正まで頼まれたときだけ書き換える。レビューだけなら指摘で止める。
- 差分だけを返し、各変更にルールidを含む理由を1行添える。
